# ひかりのゆうしゃ (Hikari no Yuusha)

ドラゴンクエスト風のブラウザRPG。単一HTMLファイル（外部素材なし）で動作します。
スマホ・PCの両対応。日本語。

▶ プレイ: https://tg2032.github.io/hikari-no-yuusha/

## 遊び方

- 十字キー / 矢印キーで移動、Aボタン（Z/Enter）で話す・進む
- 町の王様に会い、装備を整えて北東の魔王城へ
- 草むら・ダンジョンでモンスターとターン制バトル
- 教会・宿屋で自動セーブ（localStorage）

## 内容

- 3マップ（フィールド / 町 / 魔王城ダンジョン）
- 敵11種＋番竜・魔王バーン（第2形態あり）
- じゅもん5種（ホイミ・メラ・リレミト・ギラ・ベホイミ）
- さくせん自動戦闘、モンスター図鑑、ミニマップ
- BGM・効果音付き（WebAudio生成、外部ファイルなし）
- つよくてニューゲーム、冒険ランク付きクリア画面

## ファイル

- `index.html` — ゲーム本体（これ1つで完結）
